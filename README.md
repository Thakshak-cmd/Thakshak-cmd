### What I'm building

| Project | What it is | Where it got to |
| --- | --- | --- |
| **[Othello Zero](https://github.com/Thakshak-cmd/othello-zero)** | An AlphaZero-style engine trained purely by self-play — no human games, no teacher engine | Move generation verified to perft depth 9 (3,005,288 leaves, matching published counts). Runs in the browser via ONNX. **[Play it →](https://portfolio-thakshak-cmds-projects.vercel.app/Projects/othello/)** |
| **[Neural Route Finder](https://github.com/Thakshak-cmd/neural-route-finder)** | A graph neural network that learns shortest-path routing on real OpenStreetMap road data | 100% of routes reached the destination; mean length 1.027× optimal, 86.3% within 5% — with a decoder that never sees road lengths |
| **[Gatekeeper](https://github.com/Thakshak-cmd/LECAI)** | An agent that triages job boards and treats everything it fetches as something a stranger wrote to be read by a machine | Precision 1.000 against 68 real postings. Hash-chained audit log, 69 tests, offline, under a second |
| **[Public Money Trail](https://github.com/Thakshak-cmd/public-money-trail)** | UK departments publish every payment over £25,000. The data is public and effectively unusable | 34 incompatible schemas normalised into one. Merkle-anchored, so silent retroactive edits become detectable |
| **[Snake DQN](https://github.com/Thakshak-cmd/snake-dqn)** | A Deep Q-Network learning Snake through trial, error and reward | Competent play in ~100 episodes — under 30 seconds headless, off an 11-value state encoding |
| **[Dream Chronicles](https://github.com/Thakshak-cmd/dream-chronicles)** | A narrative game about a manga artist who dreams into his own books and wakes to find things left behind | Vertical slice in progress. Choices are flags scenes read to recolour themselves, not branching content trees |
